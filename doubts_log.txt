[2026-09-24] Topic: PHP static vs object method
Question: in php what is the diff btw using static function directly and using function using objects

Answer:
Static method: belongs to the class itself, called with ClassName::method(), no object state, cannot use $this.
Instance/object method: belongs to an object, called with $obj->method(), can use object properties and $this, and is preferred when behavior depends on state.
Rule: use static for stateless utility logic; use object methods for stateful, OOP behavior.
